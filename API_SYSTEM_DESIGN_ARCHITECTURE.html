04 Complete REST API Endpoints Matrix

Detailed overview of all endpoints, authentication requirements, and payloads across the platform.

Method Endpoint Auth Level Description & Functionality
GET /api/tenants Public Lists all active campus clubs for directory & search.
POST /api/tenants Public / Admin Provisions a new club workspace, theme colors, and admin credentials.
GET /api/club/:slug/events Public Fetches published events with live seat capacity & ticket pricing.
POST /api/club/:slug/events Club Admin (JWT) Creates a new campus event with venue, date, price, and deadline.
POST /api/club/:slug/registrations Public (Students) Books entry pass, generates encrypted QR, and sends email pass.
POST /api/club/:slug/scanner/validate Club Admin (JWT) Scans & verifies gate QR pass in real-time, preventing duplicates.
GET /api/club/:slug/certificate-settings Club Admin (JWT) Retrieves custom certificate template frame, signatories, and styling.
PUT /api/club/:slug/certificate-settings Club Admin (JWT) Saves custom uploaded background image, dynamic signatories, and seal.
POST /api/club/:slug/registrations/:id/send-certificate Club Admin (JWT) Renders high-resolution vector SVG certificate and emails directly to attendee.
GET /api/super-admin/dashboard Super Admin (JWT) Aggregates campus-wide revenue, leaderboard, and department metrics.
PUT /api/super-admin/tenants/:id/status Super Admin (JWT) Instantly activates or suspends any college club tenant workspace.
